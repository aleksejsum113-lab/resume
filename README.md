## Проекты

### 🥃 Самогонщик Pro — SPA-приложение (в продакшене)
> **Сайт:** https://samogon-app.vercel.app · **Код:** https://github.com/aleksejsum113-lab/samogon-app

Полноценное веб-приложение, которое я спроектировал и разработал полностью сам:

- **480+ рецептов** самогона (коньяки, виски, настойки, ликёры, биттеры, джин, ром) с пошаговой инструкцией и предрендером страниц для SEO.
- **14 интерактивных калькуляторов**: разбавление спирта, крепость браги, выход продукта, гидромодуль и др.
- **AI-ассистент «Саныч»**: чат-бот на нейросети, база знаний по самогоноварению, генерация ответов через OpenRouter API.
- **Авторизация и данные пользователей** через Firebase (Auth + Firestore), гостевой вход.
- **PWA**: офлайн-работа, установка на телефон, Service Worker с кэшированием.
- **Мультиязычность** i18n (русский / английский / немецкий / испанский).
- **SEO**: структурированные данные Schema.org (Recipe, FAQ, WebSite), sitemap (487 URL), Open Graph, Google Search Console, предрендер страниц рецептов для богатых результатов Google.
- Деплой и автодеплой через **Vercel** (GitHub → Vercel), serverless-функция для ИИ-чата.

**Чем горжусь в этом проекте:** выстроил полный цикл — от идеи и дизайна до продвижения в поисковиках, с продуманной архитектурой данных и вниманием к деталям UX.
